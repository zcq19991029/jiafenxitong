导入班级名单

支持 Excel（XLSX、XLS）、ODS、UTF-8 CSV / TSV，最大10MB。必填列：班级、姓名、学号；可选列：小组、班内序号。每组最多7人，小组留空表示待分配。Excel 学号请使用文本格式以保留前导零。同名班级的名单将替换；已有课次的班级需使用新班级名。多工作表须分别包含表头。

WorkBuddy 整理名单后，怎样导入？

让 WorkBuddy 生成含“班级、姓名、学号、小组、班内序号”的 XLSX，下载到本机；点击“导入名单”选择文件，核对人数后确认，再点“名单与分组”核对。文件中小组留空则进入待分配；WorkBuddy 生成文件不会自动写入网站。已有课次的班级请在分组管理中操作，不能覆盖整班名单。

使用说明

  1. 上课前：在「上课记分」页选好班级 → 点「新开一课」，填日期、本节任务、本节值日组。
  2. 上课中：哪个小组达标就点对应的加减按钮，本节合计和累计会自动重算。
  3. 记错了要改：
    • 数字框可以直接点进去改成任意值（小组分 0-5、手机未入袋 0-本组人数；值日填参与/应到人数，自动换算0-5分）；
    • 按「↶ 撤销」（或 Ctrl+Z）可以逐步退回，最多 60 步，跨课次也能退；
    • 某一组整节课记乱了，点该组的「↺ 清零」重来（也能撤销）；
    • 个人扣分：点姓名扣1分，点“返1”返还1分，点“清零”清空扣分；不再双击清零。
  4. 两种记分界面：「表格式」和纸质记录表长得一样，一眼对着找组；「卡片式」手机上点起来更舒服。选择会被记住。
  5. 课后：点「打印本课」出一张和纸质记录表同款的 A4 纵向记录单，可以打出来归档；数据同时自动存在本机，不用点保存。
  6. 换设备：在新设备用同一教师账号登录，记录自动同步回来（核对最新版后才开放编辑）。 JSON 备份仍然保留，作为清理浏览器数据／迁移应用时的保险绳。
