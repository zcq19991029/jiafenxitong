## 登录改成 Supabase 邮箱账号（GitHub Pages 线上站）

- 背景：上一轮把站点部署到 GitHub Pages + Supabase，但登录页仍是旧「教师账号 + 邀请码」表单，而 `supabase-cloud.js` 要求邮箱，实际登录必然失败；Pages 首屏还能打开，所以用户以为「原来的正常」。
- 决定：彻底换成 Supabase Auth 邮箱体系，不保留邀请码/重置码/启动码那套 Worker 时代的账号流程。
- 改动文件：`index.html`（闸门重写：登录/注册/忘记密码/设新密码四个面板 + 第三方与访客入口区）、`app.js`（gateShow 面板映射、doLogin/doRegister/doSendReset/doSaveRecovered/doLoginWithProvider/doGuestLogin/loadAuthOptions、boot 增加 onRecover）、`supabase-cloud.js`（整体重写：token 刷新、revision 校验、冲突保护、profiles/score_states、admin、providers 探测）、`password-ui.js`（只留改密对话框，先 verifyPassword 再 changePassword）、`styles.css`（.gate-links/.gate-alt/.btn.oauth）。
- 发布：新增 `tools/build_pages.mjs`（中性 data.js + version.json + ?v= 指纹 + 404 回首页），`pages.yml` 改为构建后上传 `pages-dist`；`checks.yml` 切到 `test_assessment / test_roster_formats / test_pages`，Worker 时代的 test_backend/test_online/build_site/test_site 不再执行。
- 新增 `tools/test_pages.mjs`：跑真实产物 + 内存版 Supabase，38 项通过（含错误密码、邮箱确认、recovery 回跳抹 token、访客登录）。
- 线上：https://zcq19991029.github.io/jiafenxitong/ ，commit 10876b8，两个 workflow 都 success，线上 version.json 与 data.js 已核对。
- 待用户在 Supabase 后台确认的三件事：URL Configuration 填 Pages 地址（否则重置邮件跳 localhost）、关闭 Confirm email（否则注册要等邮件）、可选开 GitHub/Google/匿名登录。
